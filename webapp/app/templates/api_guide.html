API Guide

secURLity exposes a JSON REST API so you can integrate URL scanning into your own tools. Free to use — 10 requests / minute / IP.

Base URL https://kendual-securlity.hf.space or http://localhost:7860 locally

Scan a URL

POST /api/predict
Request body (JSON)
application/json 
{
  "url":        "https://example.com/login",   // required
  "explain":     false,                       // optional, default false
  "enable_sgd":  false                        // optional, default false
}
Response (200 OK)
{
  "url": "https://example.com/login",
  "models": {
    "cnn_lstm": {
      "probability": 0.9823,          // 0.0 – 1.0 (malicious probability)
      "verdict":     "MAL",             // "MAL" | "BEN"
      "risk_level":  "High Risk",       // "Low Risk" | "Caution" | "Suspicious" | "High Risk"
      "latency_ms":  1.8,
      "explanation": null               // populated when explain=true
    },
    "xgboost": { /* same fields */ },
    "sgd": null                           // populated when enable_sgd=true
  },
  "ensemble": {
    "probability": 0.9901,
    "verdict":     "MAL",
    "risk_level":  "High Risk",
    "threshold":   0.5,
    "formula":    "(cnn_prob + xgb_prob) / 2"
  },
  "total_latency_ms": 2.4
}
Examples
curl 
curl -X POST https://kendual-securlity.hf.space/api/predict \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/login", "explain": false}'
Python (requests) 
import requests

resp = requests.post(
    "https://kendual-securlity.hf.space/api/predict",
    json={"url": "https://example.com/login", "explain": False},
)
data = resp.json()
print(data["ensemble"]["verdict"])        # "MAL" or "BEN"
print(data["ensemble"]["probability"])     # 0.0 – 1.0
JavaScript (fetch) 
const res = await fetch("https://kendual-securlity.hf.space/api/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: "https://example.com/login", explain: false }),
});
const data = await res.json();
console.log(data.ensemble.verdict);   // "MAL" | "BEN"

Scan History

GET /api/history?limit=50

Returns the most recent scans (max 100). URL is truncated and query string stripped for privacy. 

curl https://kendual-securlity.hf.space/api/history?limit=10
History resets when the server restarts (Hugging Face Spaces ephemeral storage).

Health Check

GET /health 
{ "status": "ok", "models_loaded": ["cnn_lstm", "xgboost"], "ensemble_threshold": 0.5 }

Rate Limits & Errors

Code Meaning
200 Scan complete — check ensemble.verdict
422 Validation error — missing or malformed url field, or URL exceeds 5000 chars
429 Rate limit exceeded — max 10 requests per minute per IP
500 Internal error — model inference failed

Tips

  • → Set "explain": true to receive the attention heatmap HTML and SHAP feature values — useful for understanding why a URL was flagged.
  • → The probability field is always a continuous score 0–1, independent of the binary verdict. Use it for ranking or custom thresholds.
  • → Well-known domains (google.com, facebook.com) may receive false-positive MAL scores — the models generalize from URL structure, not domain reputation. See the limitations section.
