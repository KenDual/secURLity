How It Works

secURLity combines two specialized AI models to analyze URLs from different angles, then ensembles their predictions for a final verdict.

📊
Training Data

All models were trained on 19,678,135 real-world URLs — no synthetic data. Dataset is 80% benign (crawled from sitemaps + international domains) and 20% malicious (aggregated from 13 public threat feeds). Training took place with a domain-based split to prevent data leakage: no domain appears in both train and test sets.

Model 1

CNN-LSTM

~1.7 ms/URL · F1 0.9888

A hybrid deep learning model that reads the URL character-by-character (like reading text), combined with 30 hand-crafted lexical features extracted from the URL structure.

Character path

Embedding → Conv1D × 2 → Stacked BiLSTM → Attention pooling. Each character gets an embedding; the LSTM reads the sequence left-to-right and right-to-left simultaneously.

Lexical path

30 features including URL length, subdomain depth, digit ratio, entropy, TLD category, presence of IP addresses, punycode, and more — passed through a small MLP.

Explainability: Attention weights from the BiLSTM are upsampled back to character level and rendered as a color heatmap — redder characters contributed more to the prediction. Top lexical features by z-score are also shown.
795K parameters · ONNX FP32 export · domain-split checkpoint for production
Model 2

XGBoost

<1 ms/URL · F1 0.9996

A gradient-boosted decision tree ensemble operating on 105 tabular features extracted directly from the URL string — no character sequences, no neural networks. Extremely fast and interpretable.

Structural (12)
URL length, host length, path depth, bare hostname flag, ratio features…
TLD features (53)
One-hot TLD (50 TLDs), suspicious TLD bucket, common TLD bucket, .vn flag (strong benign signal)…
Entropy + Keywords (8)
Shannon entropy of URL / host / path, phishing keyword flags, file extension flags…
Explainability: SHAP TreeExplainer computes exact Shapley values sub-millisecond. Each feature's contribution (positive = toward MAL, negative = toward BEN) is shown as a bar chart.
Ensemble

Final Verdict

The ensemble score is a simple average of both model probabilities:

ensemble_prob = (cnn_prob + xgb_prob) / 2
verdict = "MAL" if ensemble_prob ≥ 0.5 else "BEN"

The threshold (0.5) is configurable. Each model also has an individual verdict shown separately. The 4-tier risk level (Low Risk / Caution / Suspicious / High Risk) is derived from the raw probability regardless of the binary threshold.

Optional

SGDClassifier (HTML content)

A third model that fetches the actual HTML of the page and classifies its content using character 3–4 gram features. Useful for detecting phishing pages that look benign by URL alone.

HashingVectorizer (char 3-4 grams, 2²⁰ features) Trained on phreshphish dataset F1 0.8178 · accuracy 84.7%
Not included in ensemble. SGD requires fetching the live page HTML (1–10 seconds, may be blocked by Cloudflare). Enable it via the toggle on the scanner — result is shown separately.
⚠️ Known Limitations
  • False positives on well-known domains: URLs like https://google.com or https://facebook.com/login may be flagged as malicious. The models were trained with domain-based splitting — they generalize from URL structure, not from memorizing trusted domains.
  • Bare hostnames: https://example.com (no path) scores higher risk because threat-feed URLs rarely have paths, while benign crawled URLs typically do.
  • Not a blocklist: This tool uses ML inference, not a reputation database. A brand-new phishing domain not yet in any threat feed may still be caught via URL structure, but there are no guarantees.
